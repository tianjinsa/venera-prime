# Venera Prime 2.5.3

## 本次更新

- **减少自动缓存清理频率**：日常自动维护按本地日期每天执行一次，同一天重启应用或返回前台不再重复扫描；手动清理、缓存保留时间或容量配置变更、超过容量上限时的清理仍可正常触发。
- **调整手动检测更新交互**：检测弹窗仍在前台时，发现新版本后直接打开更新详情；已关闭弹窗时保留后台结果，不突然弹出。关于页检测到更新后显示“查看更新”，任务结果与更新操作使用主按钮，“关闭”作为次要按钮，复用现有简体中文、繁体中文和英文翻译。
- **修复更新下载的 UnimplementedError**：应用网络客户端改为复用 Dio 的原生下载实现，继续使用现有网络适配器、下载进度、取消、完整性和校验和验证流程。

## 一键更新验证

- 2.5.1、2.5.2 的旧下载实现可能报 UnimplementedError；首次请从 Release 下载对应架构 APK，手动安装 2.5.3。修复不会自动回写到已安装的旧版本。
- 随后将发布 2.5.4，作为本轮一键更新的测试目标。请在 2.5.3 的“关于”页检测更新，确认能查看 2.5.4 详情、后台下载，并通过任务入口启动系统安装。
- 安装后检查版本号、收藏、历史记录和设置是否保留。这是待实际设备执行的验证步骤，不表示该升级链路已通过真机测试。

## 请更新后验证并反馈

请相关 issue 的提出者安装 2.5.3 后，按原来的复现步骤复查。

- 如果问题已解决，请在原 issue 中确认，并及时关闭尚未关闭的 issue。
- 如果问题仍存在，请在原 issue 提供版本号、系统与设备、漫画源、复现步骤，以及必要的日志或录屏；已关闭的问题也可继续留言或重新打开。
- 日志、截图和录屏请遮盖账号、密码、令牌及 WebDAV 私有地址等敏感信息。
- 关联 issue 不代表所有设备、漫画源及服务端都已验证，也不会自动关闭这些 issue。
