# Venera Prime 2.5.1

## 本次更新

- **探索页启动 #32**（@akschy）：将探索页设为初始页面时，图源后台加载完成后会自动显示内容，无需切换页面或手动检查更新。同名图源更新后，探索页也会使用新的加载逻辑。
- **WebDAV 重复上传 #28**（@Arteiimis）：漫画源保存相同数据时跳过重复写盘和全量上传；源重载及并发保存共用串行队列，备份过程中不再出现正式数据文件短暂缺失。追更收到明确的 HTTP 429 时停止该批次同源后续请求，失败尝试按配置间隔退避，保留首次成功检查、章节基线及未读状态。
- **应用内后台更新**：Android 自动选择适合设备的 APK；点击更新后显示提示并在后台下载，可在任务中心查看进度或取消。校验完成后更新任务置顶、悬浮球呼吸提醒，点击任务才打开系统安装器；重启可恢复已下载包，包丢失或损坏后支持重新下载。关闭悬浮球不影响任务，减少动画模式下使用静态高亮。
- **更新包校验与重试**：核对文件大小、校验值、包名、新版本号及当前签名集合；安装权限返回后重新校验文件。拒绝权限或退出安装器后可以重试，取消或失败的临时下载不会妨碍后续下载。
- **漫画源可读性检查**：安装或更新源后检查样例漫画列表、详情、章节和可解码图片，提供阶段、样图及可复制的错误；检查可在后台继续，也支持手动指定漫画 ID。
- **翻页与跨章**：统一边缘点击、画廊键盘、滚轮和音量键的阅读方向与章节边界；连续模式的首末长图尚未滚完时先滚动本章内容，避免提前跨章，兼容反转点击及页边距。
- **任务入口键盘操作**：桌面可用 F6 聚焦悬浮球，再按 Enter 或空格打开任务中心。

本次包含 PR #31，感谢 @zklall 提供漫画源可读性检查、阅读导航及 Android 更新的基础实现；已适配现有后台任务并补充整合修复。
