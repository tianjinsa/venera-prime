# 阅读页边距、缓存保留与后台任务（2026-10-13）

## 使用入口

- 阅读器齿轮侧栏和“设置 → 阅读”：新增“阅读页边距”开关，默认关闭。每侧可设置0–40%，滑杆步长0.1%，也可直接输入数值。启用后替代旧固定宽度限制，停用恢复原行为；支持单漫画/设备设置。
- 连续纵向阅读在左右留边，连续横向阅读在上下留边，页面之间仍连续；画廊和双页模式保留四边。调整边距和改变视口方向时保留阅读位置，双指缩放及留白区拖动继续可用。
- “设置 → 应用”：闲置缓存保留1/3/7/30天或永不，默认7天。按最后读取时间续期，启动、恢复前台、每小时及策略改变时检查。永不仅关闭按时间清理，原容量上限继续生效。下载和本地漫画目录不参与缓存清理。
- 漫画源页面：检查、批量更新和单源更新可后台继续；新增自动更新开关，默认关闭，仅自动应用明确绑定且启用的来源更新。正常检查间隔一天，失败一小时后可重试；应用长期开启及恢复前台也会检查是否到期。
- 应用更新、源更新、收藏信息、历史刷新和追更入口显示真实后台状态及上次完成/失败/取消时间。检查新版本的结果可从任务中心重新打开。
- 各页面右下方显示可拖动的半透明任务入口，松手吸附左右边缘，闲置时弱化显示。计数为未结束任务，包括暂停的下载；任务中心优先展示未结束任务。
- 关闭任务详情或点击“后台继续”仅关闭视图；显式“取消”才请求停止，正在执行的步骤退出后再记录取消终态。失败标题与原因可长按选择、单项复制或全部复制。

后台执行指应用内离开任务页面后继续运行，不承诺系统终止应用后仍执行。下载保留原有队列恢复机制。备份恢复和存储路径变更会影响当前数据库/存储，保留模态保护，但仍显示在任务中心。

## 长任务覆盖盘点

按完整业务操作计数，下载中的各张图片合并在下载任务内，避免逐请求刷屏。

| 任务组 | 追踪入口与行为 |
| --- | --- |
| 应用版本检查 | checkUpdateUi，共享运行任务，完成结果可重开 |
| 源初始化、目录检查、脚本更新/新增安装 | source-initialization/source-check/source-catalog/source-update，初始化失败可重试；解析/保存结束后才完成 |
| 收藏漫画信息更新 | updateComicsInfo，4路并发，跨文件夹去重，离页继续 |
| 历史信息刷新 | refreshAllHistoriesStream，5路并发，保留原限速，取消后排空队列但不发新请求 |
| 网络收藏导入与同步 | importNetworkFolder，分页进度、去重、取消和部分失败结果保留 |
| 追更检查/选择文件夹 | 服务持有任务；离页不取消，显式取消不会误提交新选择 |
| 漫画及压缩包下载 | 新建/恢复/继续/暂停/失败重试/取消/完成都追踪；暂停明确显示，不伪装为已完成 |
| WebDAV上传、下载 | 只记录真正执行；自动同步关闭的no-op不造任务；阶段进度及失败可查看 |
| 漫画导入、复制与注册 | 任务覆盖整个生命周期，导入/本地扫描/路径改变串行，避免读取半复制文件 |
| 漫画导出 | 每个任务独立临时目录，避免并行导出互相清理文件 |
| 应用数据导入/导出 | 备份导出可后台，恢复数据保留模态；错误进入中心 |
| 本地扫描、存储路径变更 | 完整记录实际操作，与导入串行；扫描可后台 |
| 自动/容量触发/手动缓存清理 | 按实际清理批次聚合，读取租约防止删除正在读取的文件，删除失败不报成功 |
| 清除失效收藏、本地文件删除 | 每批真实异步目录清理独立记录；保留路径范围和符号链接检查 |
| 漫画源自定义加载对话框 | 通用LoadingDialog追踪，由源调用方关闭；只有真实取消回调才标记可取消 |

普通页面分页、详情加载和阅读预加载仍遵循页面生命周期，没有拆成任务中心中的大量独立条目。

## 状态、性能与安全处理

- 任务由应用级服务持有，与弹窗/页面生命周期分离，同一业务key的并发启动共享一次执行。
- 保留最近50个结束结果，持久化最多200个稳定业务key的完成时间与状态；临时loading/文件清理key不无限写入历史。
- 任务历史写入implicitData，不触发WebDAV上传，避免同步任务结束后自激循环。
- 悬浮计数只监听数量改变，任务进度不重建整个应用。隐藏入口时保持承载子树，避免丢失应用锁隐私遮罩。
- 贴边位置考虑左右安全区域/手势区域、键盘和视口尺寸变化；长标题与失败内容可滚动。
- 缓存老数据库迁移兼容原条目；并发读、写、清理和手动清除有回归覆盖。启动目录核对改为短队列操作，前台首图无需等待整目录扫描。
- Linux临时文件基准：10000个文件的缓存首读从约146–153ms降至4.5–6.7ms，完整核对仍在后台完成；此项不是手机耗时数据。

## 补充：更新列表左滑确认已观看

“更新”区域的漫画支持向左滑动，底部动作显示“已看完最新章节”。仅调用现有markAsRead清除当前更新标志，保留收藏条目、追更文件夹、更新标记和章节基线，不伪造阅读历史或将整部漫画标记完结。“全部漫画”区域不提供该滑动动作。

详细与简洁布局均验证：向右滑无效；向左滑只确认目标漫画，其他未读更新不变；关闭并重开数据库后仍有效；相同章节复查不重复提醒，新增章节后重新进入更新列表。16项追更回归及Android独立Profile测试均通过，邻接网格/收藏4项回归通过。手机主包路径和原历史、收藏数据库校验值保持不变。尚未发布。
