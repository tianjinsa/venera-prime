# Venera Prime 2.5.5

## 本次更新

- **修复更新下载完成后误报不完整**：在“关于”页检测更新并下载 APK 后，应用的文件类型查询可能把已完整下载的文件误判为不存在，继而显示 `FormatException: Update download is incomplete`。修正文件类型查询的原生路径传递，完整且校验通过的 APK 可进入待安装状态；仍拒绝非普通文件、字节数不符或 SHA-256 不符的文件。
- **保留更新下载的超时配置**：网络日志拦截器不再把下载设置的两分钟接收超时覆盖为十五秒，未指定超时的请求继续采用默认值；这不是整个下载过程的总时限，也不保证所有网络都能完成下载。
- **改善下载失败诊断**：区分文件类型错误与下载字节数不足；字节数不足时显示预期与实际大小，并记录响应状态及相关长度信息。新增诊断不记录下载地址。

## 一键更新验证

1. 2.5.3、2.5.4 的旧更新器可能在下载完成后误报不完整；请先从本版 Release 手动下载对应架构 APK，覆盖安装 2.5.5，无需卸载或清除数据。2.5.1、2.5.2 的旧下载实现也需先手动升级。
2. 随后发布 2.5.6 作为更新目标。在 2.5.5 的“关于”页检测更新，确认打开详情后可以后台下载，并从完成任务进入系统安装器。
3. 安装后检查版本号、收藏、历史记录和设置是否保留。新 Release 无法回写修复到已安装的旧更新器。

这些是本轮待执行的正式版本升级步骤，不表示 2.5.5 → 2.5.6 已通过真机测试。

## 请更新后验证并反馈

请相关 issue 的提出者安装 2.5.5 后，按原来的复现步骤复查。

- 如果问题已解决，请在原 issue 中确认，并及时关闭尚未关闭的 issue。
- 如果问题仍存在，请在原 issue 提供版本号、系统与设备、漫画源、复现步骤，以及必要的日志或录屏；已关闭的问题也可继续留言或重新打开。
- 日志、截图和录屏请遮盖账号、密码、令牌及 WebDAV 私有地址等敏感信息。
- 关联 issue 不代表所有设备、漫画源及服务端都已验证，也不会自动关闭这些 issue。

## 验证范围

- 本次发布准备的 58 项相关自动化回归通过，覆盖更新器、后台任务、缓存维护、网络日志和文件类型；相关 Dart 静态分析、格式和差异检查通过，未沿用旧版测试数字。
- 问题定位时，已在一台 Android 真机上复现 2.5.3 下载官方 2.5.4 APK 后误报不完整，并用本地修正的诊断包验证下载与校验完成；独立下载结果为 22,551,440 字节，SHA-256 与官方附件一致。此诊断不是正式 2.5.5 APK 的升级验证。
- 本轮按规范执行 Android、iOS、macOS、Windows、Linux x64 和 Linux ARM64 六平台构建，并核对十四个附件、构建产物哈希、Android 签名和递增版本号。
- 诊断时系统安装器要求锁屏密码，最终以 ADB 覆盖安装官方 2.5.4，应用数据保留；未宣称完成应用内端到端安装。尚未执行正式 2.5.5 → 2.5.6 真机升级，也未覆盖所有设备、安装权限交互、第三方漫画源或用户服务端。
