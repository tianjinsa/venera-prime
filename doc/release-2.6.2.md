# Venera Prime 2.6.2

## 本次更新

- **收藏夹导入与导出入口**：在收藏夹概览和本地“全部”页面的右上角菜单增加“从文件导入”和“导出”，导出时可选择一个本地收藏夹，沿用原有 JSON 格式。具体收藏夹原有的重命名、排序、导出、更新漫画信息和删除操作继续保留；补充导入导出失败提示，并修正菜单长文本溢出。
- **WebDAV 手动同步 #39**（@lzx377z）：配置 WebDAV 后，即使关闭“自动同步数据”，主页仍可手动上传、下载；配置页点击“继续”会执行选中的上传或下载，“保存”只保存配置。自动同步仍受各设备独立开关控制，排队的自动上传在执行前重新检查开关。
- **备份内容停留在旧数据**：修复 SQLite WAL 模式下直接复制主数据库、遗漏日志中已提交记录的问题。自动同步和手动导出的历史、收藏、稍后阅读、阅读统计及 Cookie 数据库均改为生成完整快照。旧备份无法补回原先未打包的记录；升级后请先从数据最完整的设备重新上传，再让其他设备下载。
- **多设备 WebDAV 备份识别**：上传版本会递增到本地及远端已知版本之后，并使用独立文件名，避免多个设备从同一备份开始使用时生成同名文件。备份日期和版本按数字排序，下载根据实际备份标识判断是否已同步，避免相同版本号的不同内容被跳过；兼容旧格式的 ETag、修改时间及缺少元数据的服务端。上传失败不再空增版本，恢复数据产生的通知不再立即触发回传。同步仍采用整包快照，不会自动合并多台设备同时产生的不同修改。
- **折叠屏侧栏和后台任务悬浮球 #40**（@zklall）：扩大侧栏设置入口的有效点击区域，并避开底部系统导航安全区；悬浮球贴边后完整保留在可见区域内，继续支持拖动和窗口尺寸变化。
- **倒序目录与跨章阅读 #40**（@zklall）：将目录显示排序与实际阅读顺序分开，分组目录同样提供排序入口。自动模式优先复用已缓存页面中的明确章节链接，无法识别时可独立指定实际阅读顺序；目录正序或倒序不再直接决定上一章、下一章的方向。连续模式返回上一章时，等待可见图片解码后对齐章末。该问题与悬浮球问题统一在 #40 跟踪，原 #41、#42 已由提出者合并到该 issue。
- **AltStore 源 #37**（@h0stg）：修正源中继承的旧应用包名和版本信息，使用 Venera Prime 实际 IPA 的版本、构建号、下载地址和大小。加入正式 Release 成功后由机器人更新源的工作流，跳过草稿和预发布版本，缺少完整 IPA 元数据时保留原源文件。

感谢 @zklall 提供 #40 的修复分支和回归测试。本版不包含 #38 的下载管理新功能提案。

## 请更新后验证并反馈

请关联 issue 的提出者安装 2.6.2 后，按原来的复现步骤复查；遇到备份内容停留在旧数据的用户，也请重新上传并在其他设备下载检查。

- 如果问题已解决，请在原 issue 中确认，并及时关闭尚未关闭的 issue。
- 如果问题仍存在，请在原 issue 提供版本号、系统与设备、漫画源、复现步骤，以及必要的日志或录屏；已关闭的问题也可继续留言或重新打开。
- 日志、截图和录屏请遮盖账号、密码、令牌及 WebDAV 私有地址等敏感信息。
- 关联 issue 不代表所有设备、漫画源及服务端都已验证，也不会自动关闭这些 issue。
