# Venera Prime 2.4.5

## 本次更新

- **发现页滚动 #29**：刷新按钮显隐改为局部更新，避免滚动方向变化时重建整个发现页及漫画网格，减少已确认的 UI 停顿。
- **网络连接复用**：封面等请求共享 HTTP 客户端，减少重复建立连接；修改代理、DNS、SNI 或证书校验设置后切换连接池，保留正在读取的响应流，各请求认证头独立。
- **历史批量删除**：使用事务批量删除，完成后统一刷新列表，避免逐条删除反复查询整张历史表。
- **收藏列表**：“全部”模式不再逐本查询阅读历史，减少大收藏夹进入及重建时的额外开销。
- **收藏图片**：修复已下载漫画的图片无法正确命中本地文件的问题；按漫画和章节标识读取本地图片，文件缺失时仍可回退到缓存或网络。
- **滚动条**：无日期等拖动标签时取消多余的下一帧重建，保留历史页日期提示更新。

## 验证范围

- 完成自动化回归与修改文件静态检查。
- Android 真机 Profile 集成测试覆盖 HTTP 连接复用、并发复用、请求认证头隔离、代理/DNS 切换、活动响应流保留、本地图片读取及临时数据库批量删除。
- 在 60Hz Android 设备上复测发现、历史及收藏页面。发现页重复滑动的整页重建尖峰明显减少；首次绘制新文字或图片仍可能存在额外开销，尚不能保证所有设备上的持续卡顿或残影均已解决。
- 连接数与数据库耗时使用受控本地服务、临时数据库验证，不代表所有漫画源的外网速度或所有设备的性能。

## 请更新后验证并反馈

请 #29 的反馈者安装 2.4.5 后，使用相同漫画源和原来的滑动方式复查。若仍有问题，请反馈设备型号、系统、屏幕刷新率、漫画源，以及首次浏览和重复浏览是否有区别；本次发布不会自动关闭 issue。
