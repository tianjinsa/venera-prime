# Venera Prime 2.5.0

## 本次更新

- **阅读页边距**：新增可开关的每侧页边距，支持 0–40% 调整，兼容单页、双页及连续阅读，保留双指缩放。连续模式仅在阅读区域两侧留边。
- **缓存自动清理**：可按闲置 1 天、3 天、7 天、30 天或永不清理；默认保留 7 天，读取图片后重新计时。下载和本地漫画不受影响，容量上限仍然生效。优化启动缓存核对，减少大量缓存时首张图片等待。
- **统一后台任务**：新增全局半透明悬浮入口与任务列表，查看任务数量、进度和结果。支持拖动贴边及角落吸附；“设置 → 应用”可关闭悬浮球，默认开启，关闭后仍可从设置查看任务。
- **后台继续**：漫画信息刷新、检查更新及其他适合的任务可离开操作页面继续执行；下载、同步、导入导出、扫描和缓存维护等任务统一显示实际状态。
- **漫画源更新**：支持一键更新已添加的漫画源，以及从绑定源目录自动更新；相关入口显示上次检查或完成时间。
- **失败信息复制**：任务失败详情支持文本选择、单条复制及复制全部错误，方便定位漫画和反馈问题。
- **追更列表左滑**：向左滑动将当前更新标记为“已看完最新章节”，仅从当前更新列表隐藏，保留收藏和追更条目；出现新章节后会再次提醒。

## 验证范围

- Flutter 静态分析通过；完整回归 236 项通过，1 项需要外部地址的可选 TLS 探测按配置跳过；Linux x64 发布构建已验证。
- Android 真机独立测试覆盖缓存、阅读页边距、悬浮入口、后台继续、收藏及历史更新；追更左滑已在桌面和 Android 测试。
- 华为 TAS-AN00 已实测悬浮球开关、重启保存、设置任务入口和拖动贴边。关闭悬浮球不影响任务服务的生命周期。
- 本次真机手动测试未覆盖长时间后台任务在系统强制回收后的行为；其他平台运行效果仍需相应设备反馈。
