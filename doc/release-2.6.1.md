# Venera Prime 2.6.1

## 本次更新

- **收藏更新检查进度**：修复启动后的自动检查在漫画因检查间隔被跳过时显示 `0/0` 的问题。进度保留收藏夹的漫画总数，并将跳过项计入已处理数量；完成后分别显示检查数与跳过数。空收藏夹显示“没有需要检查的漫画”，后台任务列表和详情不再显示无意义的 `0/0`。
- **备份导入兼容性**：导入 `.venera` 备份时，空文件或仅含空白的图源脚本不再阻断整份数据恢复；跳过这些脚本并列出文件名，本机同名非空脚本会保留。手动导入和 WebDAV 恢复均提供提示，并补充简体、繁体中文翻译。配置、账号数据、数据库、备份清单和压缩包安全校验仍然保留，导入失败时继续执行原有回滚。

## 请更新后验证并反馈

请关联 issue 的提出者安装 2.6.1 后，按原来的复现步骤复查；遇到上述两项问题的用户也请复查自动检查进度和备份导入结果。

- 如果问题已解决，请在原 issue 中确认，并及时关闭尚未关闭的 issue。
- 如果问题仍存在，请在原 issue 提供版本号、系统与设备、漫画源、复现步骤，以及必要的日志或录屏；已关闭的问题也可继续留言或重新打开。
- 日志、截图和录屏请遮盖账号、密码、令牌及 WebDAV 私有地址等敏感信息。
- 关联 issue 不代表所有设备、漫画源及服务端都已验证，也不会自动关闭这些 issue。
