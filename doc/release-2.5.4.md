# Venera Prime 2.5.4

## 本次更新

- **一键更新测试版本**：在 2.5.3 修复版基础上仅递增版本与构建号，未增加功能变更。用于验证 2.5.3 能发现新版本、查看详情、在后台下载更新，并通过系统安装器升级到 2.5.4。
- **发布范围说明**：当前更新器只检测正式 Release，因此本版按正式 Release 发布，不是预发布标签；所有启用更新检查的用户均可看到本版。每日缓存维护、更新交互和下载实现的修复已经包含在 2.5.3 中，不作为本版新增功能。

## 一键更新验证

1. 仍使用 2.5.1 或 2.5.2 时，请先从 Release 下载对应架构 APK，手动安装 2.5.3；旧版下载逻辑可能报 UnimplementedError，无法由新 Release 自动修复。
2. 在 2.5.3 的“关于”页手动检测更新，检查是否直接打开 2.5.4 详情；关闭检测弹窗时，结果应保留在后台任务中，不突然弹出。
3. 点击更新，查看后台任务的下载进度与错误信息；下载完成后通过任务入口启动系统安装，按系统要求授予安装权限。
4. 安装后确认版本为 2.5.4，收藏、历史记录和设置仍保留。也可另行检查启用“启动时检查更新”后的检测流程。

上述为用户可执行的验证步骤，不表示已完成真机升级测试。发现失败时，请提供设备、系统、源版本和目标版本、操作步骤，以及后台任务中的错误信息。

## 请更新后验证并反馈

请相关 issue 的提出者安装 2.5.4 后，按原来的复现步骤复查。

- 如果问题已解决，请在原 issue 中确认，并及时关闭尚未关闭的 issue。
- 如果问题仍存在，请在原 issue 提供版本号、系统与设备、漫画源、复现步骤，以及必要的日志或录屏；已关闭的问题也可继续留言或重新打开。
- 日志、截图和录屏请遮盖账号、密码、令牌及 WebDAV 私有地址等敏感信息。
- 关联 issue 不代表所有设备、漫画源及服务端都已验证，也不会自动关闭这些 issue。
