# Venera Prime 2.4.3

## 修复

- 修复重叠追更检查覆盖未读标记的问题，重复检查只统计实际新增更新。
- 取消追更检查后不再写入迟到的请求结果，切换追更文件夹保留并展示已有未读更新。
- 保存章节 ID 基线，识别同一天新增章节；首次建立基线不把全部章节报为更新。
- 切回已有追更记录的文件夹时继续检测新章节，避免静默初始化吞掉更新。
- 阅读后的追更列表和首页计数同步刷新，保留进入任意章节即标记整部已读的现有规则。
- 修复 Android 自选存储目录的下载完整性校验，调整下载元数据读写以兼容 SAF。
- 恢复漫画源目录中版本号下的描述。
- 历史记录增加本地搜索及上次阅读日期、时间。
- Linux AppImage 打包 WebKit 库、辅助进程、注入模块和网络依赖。

## 验证范围

- 自动化回归覆盖重叠检查、同日新增章节、取消请求、基线建立、未读列表和已读刷新。
- Android 集成测试使用独立包名及隔离临时数据，避免测试运行器卸载普通应用；测试不使用用户账户或 WebDAV 设置。
- 第三方漫画源的章节标识变化、ARM64 SteamOS 兼容性仍需目标环境验证。
