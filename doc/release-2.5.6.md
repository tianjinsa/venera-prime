# Venera Prime 2.5.6

## 本次更新

- **一键更新测试版本**：在 2.5.5 修复版基础上仅递增版本和构建号，没有新增功能变更。用于检查 2.5.5 是否能够发现新版、查看详情、后台下载完整 APK、进入待安装状态，并通过系统安装器升级到 2.5.6。
- **发布范围说明**：现有更新器只检测正式 Release，因此本版按正式 Release 发布，不是预发布版；所有启用更新检查的用户都能看到。下载完成后误报不完整、超时配置和诊断调整已包含在 2.5.5，不作为本版新增修复。

## 一键更新验证

1. 2.5.4 及更早版本的旧更新器可能无法完成下载校验；请先从 Release 手动下载对应架构 APK，覆盖安装 2.5.5，不要卸载或清除应用数据。
2. 在 2.5.5 的“关于”页检测更新，确认可以查看 2.5.6 详情；关闭检测弹窗时，结果应保留在后台任务中，不突然弹出。
3. 点击更新，检查后台下载进度。下载完成后应进入待安装状态，不再对完整文件提示 `Update download is incomplete`；从完成任务启动系统安装器，并按系统要求确认权限和安装。
4. 安装后确认版本为 2.5.6，收藏、历史记录和设置仍保留。也可另行检查“启动时检查更新”的流程。

上述是正式版本的待执行验证步骤，不表示 2.5.5 → 2.5.6 已通过真机升级测试。失败时请提供设备与系统、源版本和目标版本、操作步骤，以及任务中的错误信息。

## 请更新后验证并反馈

请相关 issue 的提出者安装 2.5.6 后，按原来的复现步骤复查。

- 如果问题已解决，请在原 issue 中确认，并及时关闭尚未关闭的 issue。
- 如果问题仍存在，请在原 issue 提供版本号、系统与设备、漫画源、复现步骤，以及必要的日志或录屏；已关闭的问题也可继续留言或重新打开。
- 日志、截图和录屏请遮盖账号、密码、令牌及 WebDAV 私有地址等敏感信息。
- 关联 issue 不代表所有设备、漫画源及服务端都已验证，也不会自动关闭这些 issue。
