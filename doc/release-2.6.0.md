# Venera Prime 2.6.0

## 本次更新

- **阅读页实时调节页边距 #33**（@suppermanzero）：底部工具栏新增页边距按钮，可展开开关、连续滑杆和精确数值输入。拖动时立即预览，松手后保存，无需退出设置页查看效果；沿用漫画、设备和全局设置的优先级，保留阅读位置与单图画廊已有的相对缩放。
- **双页与多图画廊单张移位 #34**（@MisakaTukasa）：底部工具栏新增前移、后移一张图片的操作，可将 `P3 | P4` 调整为 `P4 | P5`，方便对齐跨页图；普通翻页仍按每屏图片数量前进。支持阅读方向、首页单张和旋转后的位置换算，切换章节时重置临时分组偏移。
- **收藏夹检测信息 #35**（@suppermanzero）：移除漫画列表顶部常驻的“尚未检查”和上次检查时间；检查操作仍可使用，进度与结果保留在后台任务中。
- **连续阅读跨章节 #36**（@zklall）：到已加载章节的实际边界后，普通滑动、边缘点击、滚轮、触控板及阅读方向对应的方向键可继续进入相邻章节；整章不足一屏时也能继续阅读，边界回弹不再吞掉翻页点击。保留章节分组、反向点击及长图未读完时先滚动的行为，小幅移动、取消手势和多指缩放不触发切章。整合了 @zklall 提供的修复及回归覆盖，感谢贡献。
- **后台任务面板重复打开**：连续点击悬浮球或使用键盘重复激活时，只保留一个任务列表面板；查看任务详情时再次点击也不会叠加列表，关闭后仍可重新打开。

## 请更新后验证并反馈

请关联 issue 的提出者安装 2.6.0 后，按原来的复现步骤复查。

- 如果问题已解决，请在原 issue 中确认，并及时关闭尚未关闭的 issue。
- 如果问题仍存在，请在原 issue 提供版本号、系统与设备、漫画源、复现步骤，以及必要的日志或录屏；已关闭的问题也可继续留言或重新打开。
- 日志、截图和录屏请遮盖账号、密码、令牌及 WebDAV 私有地址等敏感信息。
- 关联 issue 不代表所有设备、漫画源及服务端都已验证，也不会自动关闭这些 issue。
