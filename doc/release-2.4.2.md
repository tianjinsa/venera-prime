# Venera Prime 2.4.2

## 修复

- 修复手动代理地址解析，统一漫画源请求与文件下载的代理适配，并支持 Basic 代理认证。
- 修复阅读进度条反复拖动可能导致无法继续滚动的问题，增加实时页码显示，并改进连续模式可见页码判定。
- 调整横屏连续阅读的触摸范围，使两侧留白包含在滚动区域内。
- 修复低高度横屏首页侧栏溢出，支持滚动访问底部操作。
- 修复漫画源尚未加载或已移除时本地漫画区块的空值错误，并在源状态变化时刷新。
- 全部收藏统一更新漫画信息，合并重复请求、显示失败标题；修复多目标移动和同文件夹移动的问题，并保留翻译标签。
- 修复网络缓存替换与容量计算、不同授权上下文的缓存匹配，以及 HEAD 校验失败后的请求回退。
- 分块下载失败后等待其他请求结束再关闭文件，使用未压缩的字节范围下载。
- WebDAV 上传成功后再清理旧备份，保留本次上传的同名文件，并恢复备份数量上限。

## 验证

- Flutter 静态分析、自动化测试和 Android 调试构建通过。
- 测试覆盖本地 HTTP 代理认证、WebDAV 上传失败保护、缓存 HEAD 失败回退，以及原生 ZIP 备份导入导出。
- Android 实机已验证进度条往返、连续滚动和画廊 RTL 翻页。横屏留白竖向拖动、缩放复位及其他平台仍需补充验证。
