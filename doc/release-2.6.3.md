# Venera Prime 2.6.3

## 本次更新

- **旧备份导入后重启白屏**：部分旧版 `.venera` 备份的“稍后阅读”数据库使用旧字段，导入后首页读取失败，即使稍后阅读列表为空也会触发白屏。本版补齐数据库迁移，恢复后可正常进入首页，并继续添加、删除稍后阅读条目；已有条目、来源和加入时间会保留。已在受影响手机上覆盖安装修复构建，保留原有数据后正常启动。
- **数据库迁移失败时保留数据**：旧表转换使用事务，失败时回滚；不支持的表结构会报告初始化或导入失败，避免将结构不兼容的完整数据库误当成损坏文件而重建。

- 如果问题已解决，请在原 issue 中确认，并及时关闭尚未关闭的 issue。
- 如果问题仍存在，请在原 issue 提供版本号、系统与设备、漫画源、复现步骤，以及必要的日志或录屏；已关闭的问题也可继续留言或重新打开。
- 日志、截图和录屏请遮盖账号、密码、令牌及 WebDAV 私有地址等敏感信息。
- 关联 issue 不代表所有设备、漫画源及服务端都已验证，也不会自动关闭这些 issue。
